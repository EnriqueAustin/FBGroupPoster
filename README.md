# FB Group Poster

Assisted drip poster for Facebook groups across multiple businesses. A local-only web UI (127.0.0.1:8787) plans posts, paces them, and fills Facebook's composer in a visible Chrome window.

```bash
npm install
npx playwright install chrome
npm start
```

See [ARCHITECTURE.md](ARCHITECTURE.md) and [src/facebook/runner/README.md](src/facebook/runner/README.md), and for the Instagram module [src/instagram/PLAN.md](src/instagram/PLAN.md).
